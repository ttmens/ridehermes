# RideHermes 项目简介

## 一句话描述

**AI 驱动的智能出行平台**——让乘客通过语音对话完成叫车，让司机高效接单，让运营轻松管理。

## 愿景

> 用 AI 重新定义出行体验，让叫车像对话一样自然。

## 核心价值

| 角色 | 痛点 | RideHermes 解决方案 |
|------|------|---------------------|
| 乘客 | 手动输入地址繁琐 | 语音 AI 叫车，说一句话就搞定 |
| 司机 | 订单来源分散 | 统一接单平台，智能派单 |
| 运营 | 多系统切换 | 一站式管理后台 |
| 开发者 | 集成复杂 | MCP Server 标准协议，AI 智能体即插即用 |

## 核心功能

### 乘客端
- 🎤 **语音 AI 叫车**：说出目的地，AI 自动理解并下单
- 🗺️ **高德地图**：精准定位、路线规划、POI 搜索
- 📍 **实时追踪**：司机位置、行程进度实时可见
- 📋 **订单管理**：历史订单、订单详情、取消订单

### 司机端
- 🟢 **上线/下线**：一键切换接单状态
- 📱 **订单接收**：实时推送，快速接单/拒单
- 🧭 **导航集成**：接单后自动导航到目的地
- 💰 **收入统计**：今日/本周/本月收入一目了然

### 管理后台
- 👥 **用户管理**：乘客、司机账号管理
- 📦 **订单管理**：全平台订单查看与处理
- 🗺️ **实时监控**：在线司机/乘客位置监控
- 🤖 **智能体管理**：MCP API Key 生成与管理

### MCP Server
- 🔌 **标准协议**：Model Context Protocol，AI 智能体即插即用
- 🛠️ **5 个工具**：预估、下单、查询、取消、历史
- 🔐 **安全认证**：API Key + User ID 双重认证
