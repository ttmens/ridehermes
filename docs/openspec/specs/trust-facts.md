# 信任与事实规格

> MODIFIED | ADR-004

## 目标态

- **中心**：签名发布客观事实（完单数、取消率、履约记录、三证状态）
- **边缘**：各 Agent 自行解读「什么是好匹配」
- **禁止**：中心统一信誉评分作为排序依据

## R0 过渡

| 产物 | 状态 | 说明 |
|------|------|------|
| admin `/trust-scores` | ⚠️ 过渡 | 四维评分 UI，待重构为事实面板 |
| `Evaluation` 模型 | 部分 | 无乘客提交 API |
| `TrustScore` 服务 | 部分 | 统计 stub |

## 文档要求

- PRD/C4 不得将 trust-scores 标为「目标态已完成」
- 新功能默认写入「事实发布」而非「平台评星」
