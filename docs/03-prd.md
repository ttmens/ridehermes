# RideHermes 产品需求文档 (PRD)

> 版本: v2.0 | 状态: 已实现 | 最后更新: 2026-06-24

## 1. 产品概述

### 1.1 产品定位

**RideHermes** 是一个 AI-First 的智能出行平台，核心差异化：
- 🎤 **语音叫车**：说出目的地即可下单
- 🔌 **MCP 集成**：AI 智能体通过标准协议调用
- 📱 **全端覆盖**：乘客端、司机端、管理后台

### 1.2 目标用户

| 用户角色 | 描述 | 核心需求 |
|----------|------|----------|
| 乘客 | 出行需求方 | 快速叫车、实时追踪、安全到达 |
| 司机 | 运力提供方 | 高效接单、收入稳定、操作简单 |
| 运营 | 平台管理方 | 用户管理、订单监控、数据分析 |
| 开发者 | AI 集成方 | 标准接口、文档完善、稳定可靠 |

## 2. 用户故事

### US-1: 乘客语音叫车

**作为**一名乘客，**我想要**用语音说出目的地来叫车，**以便**不用手动输入地址。

**验收标准：**
- [x] 点击麦克风按钮开始录音
- [x] 语音识别准确率 > 90%
- [x] AI 正确解析目的地意图
- [x] 显示订单预览（地址、预估价格）
- [x] 确认后自动创建订单并派单

### US-2: 乘客实时追踪

**作为**一名乘客，**我想要**在地图上看到司机的实时位置，**以便**知道司机什么时候到。

**验收标准：**
- [x] 地图显示司机位置图标
- [x] 位置更新延迟 < 3 秒
- [x] 显示预计到达时间
- [x] 行程路线实时绘制

### US-3: 司机接单

**作为**一名司机，**我想要**收到新订单推送并快速接单，**以便**不错过生意。

**验收标准：**
- [x] 新订单实时推送（< 2 秒）
- [x] 显示乘客上车点距离
- [x] 一键接单/拒单
- [x] 接单后自动导航

### US-4: 运营管理

**作为**运营人员，**我想要**在后台查看所有订单和在线司机，**以便**及时处理异常。

**验收标准：**
- [x] 订单列表（筛选、搜索、分页）
- [x] 订单详情（完整信息、状态流转）
- [x] 在线司机地图展示
- [x] 用户启用/禁用

### US-5: AI 智能体叫车

**作为**一个 AI 智能体，**我想要**通过 MCP 协议调用打车服务，**以便**用户可以直接对 AI 说"帮我叫辆车"。

**验收标准：**
- [x] MCP Server 实现 5 个标准工具
- [x] API Key + User ID 认证
- [x] 预估、下单、查询、取消、历史功能完整
- [x] npm 包可正常安装使用
