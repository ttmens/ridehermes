# RideHermes 设计系统

> 统一的视觉规范与组件库

## 1. 品牌色彩

### 主色

| 名称 | 色值 | 用途 |
|------|------|------|
| **RideHermes Blue** | `#1890FF` | 主按钮、链接、选中状态 |
| **RideHermes Dark** | `#003A8C` | 深色背景、标题 |
| **RideHermes Light** | `#E6F7FF` | 浅色背景、卡片 |

### 功能色

| 名称 | 色值 | 用途 |
|------|------|------|
| **Success** | `#52C41A` | 成功状态、完成 |
| **Warning** | `#FAAD14` | 警告状态、待处理 |
| **Error** | `#FF4D4F` | 错误状态、取消 |
| **Info** | `#1890FF` | 信息提示 |

### 中性色

| 名称 | 色值 | 用途 |
|------|------|------|
| **Title** | `#262626` | 标题文字 |
| **Primary Text** | `#595959` | 正文文字 |
| **Secondary Text** | `#8C8C8C` | 次要文字 |
| **Border** | `#D9D9D9` | 边框 |
| **Divider** | `#F0F0F0` | 分割线 |
| **Background** | `#F5F5F5` | 页面背景 |

## 6. 组件规范

### 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| **Primary** | 蓝色背景，白色文字 | 主要操作 |
| **Default** | 白色背景，灰色边框 | 次要操作 |
| **Text** | 无边框，蓝色文字 | 链接式操作 |
| **Danger** | 红色背景，白色文字 | 危险操作 |

### 订单 / A2A 阶段标签

| 阶段 | 颜色 | 背景 | 说明 |
|------|------|------|------|
| Intent 声明 | `#1890FF` | `#E6F7FF` | matching/recurring 创建 |
| Offer 协商 | `#722ED1` | `#F9F0FF` | 司机报价中 |
| Commit 缔约 | `#52C41A` | `#F6FFED` | 已确认 |
| 执行中 | `#13C2C2` | `#E6FFFB` | 行程进行 |
| Settle 完成 | `#8C8C8C` | `#FAFAFA` | 已清算 |
| 已取消 | `#FF4D4F` | `#FFF1F0` | — |

R0 过渡：仍可使用原「待派单/已派单」色，映射见 [`api/overview.md`](../api/overview.md)。

## 8. 服务等级 UX（意图本体）

| 维度 | UI 要求 |
|------|---------|
| **语言** | 企业/乘客 Intent 表单可选；admin 企业详情展示 |
| **无障碍** | 标记需无障碍车辆；列表 icon + tooltip |
| **隐私级** | 企业行程隐私级别（内部/对外脱敏） |

R0：字段规格见 [`openspec/specs/a2a-protocol.md`](./openspec/specs/a2a-protocol.md)；部分 API 未暴露，UI 预留占位。
