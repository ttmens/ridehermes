## 角色说明

| 角色 | 描述 | 主要操作 |
|------|------|----------|
| **乘客** | 出行需求方 | 语音叫车、手动叫车、追踪行程、支付 |
| **司机** | 运力提供方 | 上线接单、导航到目的地、完成行程 |
| **运营人员** | 平台管理方 | 用户管理、订单监控、数据分析 |
| **AI 智能体** | 第三方集成 | 通过 MCP 协议调用打车能力 |

## 外部依赖

| 服务 | 用途 | 风险等级 |
|------|------|----------|
| **高德地图** | 地图显示、定位、POI、路线规划 | 中 |
| **短信服务** | 注册验证码、订单通知 | 低 |
| **支付服务** | 订单支付（v2.2） | 低 |
