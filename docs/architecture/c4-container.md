## 容器详情

### 1. 乘客 App (Flutter)

| 属性 | 值 |
|------|-----|
| **技术栈** | Flutter 3.24+ / Dart 3.5+ |
| **状态管理** | Riverpod 2.x |
| **地图** | amap_flutter_map |
| **职责** | 语音叫车、订单管理、行程追踪 |
| **包大小** | 79MB (APK) |

### 2. 司机 App (Flutter)

| 属性 | 值 |
|------|-----|
| **技术栈** | Flutter 3.24+ / Dart 3.5+ |
| **状态管理** | Riverpod 2.x |
| **职责** | 接单、行程状态更新、收入查看 |
| **包大小** | 77MB (APK) |

### 3. 管理后台 (React)

| 属性 | 值 |
|------|-----|
| **技术栈** | React 18 + TypeScript |
| **UI 框架** | Ant Design 5.x |
| **构建工具** | Vite 5.x |
| **页面数** | 12 个 |
| **端口** | 3002 |

### 4. 后端 API (Go)

| 属性 | 值 |
|------|-----|
| **技术栈** | Go 1.22+ |
| **HTTP 框架** | Gin |
| **ORM** | GORM |
| **代码量** | 52 个 Go 文件 |
| **端口** | 8686 |

**内部结构：**
```
internal/
├── handler/      # HTTP 处理器 (10 个)
├── service/      # 业务逻辑 (10 个)
├── repository/   # 数据访问 (7 个)
├── model/        # 数据模型 (11 个)
├── middleware/   # 中间件
├── router/       # 路由注册
└── ws/           # WebSocket
```

### 5. MCP Server (Node.js)

| 属性 | 值 |
|------|-----|
| **技术栈** | TypeScript + Node.js 20+ |
| **协议** | MCP (Model Context Protocol) |
| **职责** | AI 智能体接入 |
| **发布** | npm (ridehermes-mcp-server) |

**提供的工具：**
- `ride_estimate` - 预估费用
- `ride_book` - 创建订单
- `ride_status` - 查询状态
- `ride_cancel` - 取消订单
- `ride_history` - 历史记录

### 6. MySQL

| 属性 | 值 |
|------|-----|
| **版本** | 8.0 |
| **职责** | 业务数据持久化 |
| **表数量** | 7 张核心表 |

**核心表：**
- `users` - 用户（管理员/乘客/司机）
- `drivers` - 司机档案
- `vehicles` - 车辆信息
- `orders` - 订单
- `locations` - GPS 位置记录
- `dispatch_logs` - 派单记录
- `ai_conversations` - AI 对话记录

### 7. Redis

| 属性 | 值 |
|------|-----|
| **版本** | 7.2+ |
| **职责** | 位置缓存、在线状态、派单队列 |
| **特性** | GEO 命令支持附近搜索 |

## 数据流

### 叫车流程

```
乘客App ──创建订单──→ Go API ──保存订单──→ MySQL
                        │
                        ├──查询附近司机──→ Redis (GEO)
                        │
                        └──推送订单──→ WebSocket ──→ 司机App
```

### 位置更新流程

```
司机App ──上报位置──→ WebSocket ──更新位置──→ Redis
                              │
                              └──广播给乘客──→ 乘客App
```
