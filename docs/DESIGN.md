# RideHermes 设计系统

> 统一的视觉规范与组件库

## 1. 品牌色彩

### 主色

| 名称 | 色值 | 用途 |
|------|------|------|
| **RideHermes Blue** | `#1890FF` | 主按钮、链接、选中状态 |
| **RideHermes Dark** | `#003A8C` | 深色背景、标题 |
| **RideHermes Light** | `#E6F7FF` | 浅色背景、卡片 |

### 功能色

| 名称 | 色值 | 用途 |
|------|------|------|
| **Success** | `#52C41A` | 成功状态、完成 |
| **Warning** | `#FAAD14` | 警告状态、待处理 |
| **Error** | `#FF4D4F` | 错误状态、取消 |
| **Info** | `#1890FF` | 信息提示 |

### 中性色

| 名称 | 色值 | 用途 |
|------|------|------|
| **Title** | `#262626` | 标题文字 |
| **Primary Text** | `#595959` | 正文文字 |
| **Secondary Text** | `#8C8C8C` | 次要文字 |
| **Border** | `#D9D9D9` | 边框 |
| **Divider** | `#F0F0F0` | 分割线 |
| **Background** | `#F5F5F5` | 页面背景 |

## 2. 字体规范

### 字体族

```css
font-family: -apple-system, BlinkMacSystemFont, 'Segoe UI', Roboto, 
             'Helvetica Neue', Arial, 'Noto Sans', sans-serif;
```

### 字号层级

| 层级 | 大小 | 行高 | 用途 |
|------|------|------|------|
| **H1** | 30px | 38px | 页面标题 |
| **H2** | 24px | 32px | 区块标题 |
| **H3** | 20px | 28px | 卡片标题 |
| **H4** | 16px | 24px | 小标题 |
| **Body** | 14px | 22px | 正文 |
| **Caption** | 12px | 20px | 说明文字 |

## 3. 间距系统

基于 8px 网格系统：

| 名称 | 值 | 用途 |
|------|-----|------|
| **xs** | 4px | 紧凑间距 |
| **sm** | 8px | 小间距 |
| **md** | 16px | 标准间距 |
| **lg** | 24px | 大间距 |
| **xl** | 32px | 区块间距 |
| **xxl** | 48px | 页面边距 |

## 4. 圆角规范

| 名称 | 值 | 用途 |

| **sm** | 2px | 小元素 |

## 6. 组件规范

### 按钮

| 类型 | 样式 | 用途 |
|------|------|------|
| **Primary** | 蓝色背景，白色文字 | 主要操作 |
| **Default** | 白色背景，灰色边框 | 次要操作 |
| **Text** | 无边框，蓝色文字 | 链接式操作 |
| **Danger** | 红色背景，白色文字 | 危险操作 |

### 订单状态标签

| 状态 | 颜色 | 背景 |
|------|------|------|
| 待派单 | `#FAAD14` | `#FFFBE6` |
| 派单中 | `#1890FF` | `#E6F7FF` |
| 已接单 | `#52C41A` | `#F6FFED` |
| 行程中 | `#722ED1` | `#F9F0FF` |
| 已完成 | `#8C8C8C` | `#FAFAFA` |
| 已取消 | `#FF4D4F` | `#FFF1F0` |

## 7. 响应式断点

| 名称 | 宽度 | 说明 |
|------|------|------|
| **xs** | < 576px | 手机 |
| **sm** | ≥ 576px | 大手机 |
| **md** | ≥ 768px | 平板 |
| **lg** | ≥ 992px | 小屏电脑 |
| **xl** | ≥ 1200px | 大屏电脑 |
